# Изображения «Лимиты»

Публичный репозиторий выбранных обложек, иллюстраций и миниатюр для Дзена. Редакционная система, рукописи, промпты, паспорта, референсы и журналы остаются в приватном `MaksZakharov/limita`.

## Структура

```text
Статьи/
  П-002/
    глава-01/
      cover_v01.jpg
      preview_v01.jpg
      illustration-01_v01.jpg
    глава-02/
      cover_v01.jpg
      preview_v01.jpg
```

Это пример путей, не существующие изображения и не готовая пилотная статья. ID повести — `П-NNN`, главы — `глава-NN`. Версии начинаются с `v01`; при правке создавать новую версию, прежнюю не перезаписывать и не удалять. Выкладывать только выбранные изображения, пригодные для публичного доступа; никаких персональных данных и внутренних файлов.

Ссылки для Markdown — только:
`https://raw.githubusercontent.com/MaksZakharov/limita_images/main/Статьи/П-002/глава-01/cover_v01.jpg`

Кириллицу допустимо percent-encode. Помимо JPG допустимы JPEG, PNG и WebP. Просмотр GitHub `blob/`, другие репозитории/ветки и локальные пути не являются ссылками для пакета Дзена. Перед передачей открыть raw-ссылку и проверить доступность, настоящее изображение и маленькое превью. Публикует в Дзене только Макс; этот репозиторий ничего не публикует автоматически.

Изображения Дзена в приватном `limita` не хранить. Исторический брендинг в `limita/Брендинг/` сохранён отдельно и не является пакетом статьи.
